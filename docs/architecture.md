## 三、SOP 十步流程架构

| 步骤 | 页面 | 功能 | 数据来源 |
|------|------|------|---------|
| 1. 需求输入 | S1 | 用户输入地块参数 | Manual |
| 2. 初步筛选 | S2 | 基础条件过滤 | POI + Mock |
| 3. 合规检查 | S3 | 生态红线/耕地保护 | engine.js + rules.json |
| 4. 空间评估 | S4 | 地形/交通/资源 | engine.js + rules.json |
| 5. 经济分析 | W1-W3 | 投资回报/运营成本 | Mock |
| 6. 市场调研 | W4-W6 | 客群/竞品/需求 | Mock |
| 7. 综合评分 | W7 | 四维加权计算 | engine.js |
| 8. 决策建议 | W8 | GO/PAUSE/CONDITIONAL/NO-GO | engine.js |
| 9. 结果展示 | W9 | 评分详情 + 建议 | engine.js |
| 10. 报告导出 | W9 | 生成评估报告（模拟） | Local |

## 四、数据流转架构

```
用户输入
  │
  ▼

  │
  ▼
S2 → S3 → S4（认证 → 合规 → 空间）
  │
  ▼
W1 → W2 → W3（经济分析）
  │
  ▼
W4 → W5 → W6（市场调研）
  │
  ▼
W7（综合评分，调用 engine.js）
  │
  ▼
W8（决策建议）
  │
  ▼
W9（结果展示 + trace.js 记录）
  │
  ▼
本地存储（wx.setStorageSync）
```

## 五、技术栈架构

| 层级 | 技术 | 说明 |
|------|------|------|
| **运行环境** | 微信小程序基础库 3.3.4 |  |
| **前端框架** | 微信小程序原生框架 | WXML + WXSS + JS |
| **路由管理** | app.json（pages 配置） | 13个页面 |
| **数据存储** | wx.setStorageSync / getStorageSync | 本地存储 |
| **决策引擎** | engine.js + rules.json | 四维评分 |
| **数据获取** | fetcher.js（当前 Mock） | 预留腾讯地图 API 接口 |
| **决策日志** | trace.js（当前未集成） | 记录评估历史 |
| **构建工具** | 微信开发者工具 | 上传 + 预览 + APK 构建 |
